# 💻 Projeto - Google Glass

Este projeto foi desenvolvido durante o curso de HTML5 e CSS3 do professor Gustavo Guanabara.

## 📚 Sobre o projeto

O objetivo deste site é apresentar informações sobre o Google Glass, incluindo imagens, vídeos e conteúdos interativos.

## 🚀 Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (utilizado para pequenas interações na página)

## ✨ Funcionalidades

- Navegação entre páginas  
- Exibição de imagens e vídeos  
- Reprodução de áudio e vídeo  
- Interações com JavaScript (como troca de imagens no menu)
